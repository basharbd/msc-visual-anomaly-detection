# Fixed-budget reference augmentation — completed

900 verified evaluations (225 matched category/reference/condition groups, four variants). All banks contain 8,192 patch embeddings. See [protocol](../../protocols/reference_augmentation.md), [macro results](macro.csv), [category-level results](per_category.csv), [paired per-run results](per_run.csv), and [factorial interaction](factorial_interaction_pp.csv).

Strong blur: blur augmentation improves image AUROC by 1.54 pp and pixel AUPRO by 0.16 pp. Clean pixel AUPRO decreases by 0.10 pp. The 13/15 positive image-level category effects are descriptive, not independent statistical evidence. See [audit](../final_scientific_analysis/audit.json) and [publication assets](../publication_assets/).
