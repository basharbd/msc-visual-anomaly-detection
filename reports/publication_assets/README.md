# Final scientific figures and tables

Verified result package, 27 November 2026. Data source: HPC night run 30402340; final summary job 30404718. All 900 ablation evaluations and 225 threshold comparisons are included. Figures are PDF and preview PNG; quantitative charts are vector graphics and the image panel embeds raster images. Ten figures are generated by the analysis notebooks using scripts/visualize.py. The standard CLI generates figures 01–08; Notebook 05 additionally generates figures 09–10. Tables are generated as CSV and LaTeX (booktabs required). Regenerate with Python, pandas, NumPy and Matplotlib: python scripts/visualize.py --output outputs/publication_assets (from the repository root). Use an unused destination; the verified files here remain unchanged.

Ablation uses one true normal reference per run, 15 categories, 3 fixed reference choices, 4 banks, 5 image conditions. Each bank contains 8192 patch embeddings. A paired gain compares against rotation-only at the same condition; a robustness gap compares against the same variant on clean images. FPR and FNR use the baseline only and a frozen normal-only threshold. F1-max is threshold-optimized separately, not fixed-threshold performance.

The strongest blur augmentation result is +1.5401 percentage points in image AUROC and +0.1571 pp in pixel AUPRO under blur radius 1.50. Clean AUPRO decreases by 0.1039 pp. Category differences are heterogeneous; reference choices share test images, so do not treat them as independent replicates or confidence intervals. No claim of independent external validation, significance, or reduced fixed-threshold false alarms for the augmented method. The empirical scope is one-shot detection, as described in the thesis. Zero-shot methods are discussed as related work, not evaluated experimentally. Archived baseline audit records two localized Screw strong-blur map differences; image-level metrics identical and largest per-run AUPRO difference 0.001012 pp. See ../final_scientific_analysis/audit.json.

Figures 01–02: all four variants across five conditions; 03–04: category-level paired strong-blur effects; 05: frozen threshold; 06: descriptive reference-choice sensitivity; 07: clean baseline category comparison; 08: macro changes under controlled perturbations; 09: selected paired test images and anomaly maps; 10: paired Bottle scores. Figure 01/02 use a restricted y-axis to resolve small differences; labels report absolute metrics. Table 01 includes all six metrics and 20 variant-condition cells, table 02 paired effects and clean-relative gaps, table 03 category effects, table 04 threshold results, table 05 reference sensitivity. Original source CSV files are unchanged.

The canonical input files are in the sibling report directories. No duplicate data copies are required.

## Regenerating the archive-backed figures

Initialize the pinned AnomalyDINO submodule, install the CPU-only dependencies, and point the environment variables at the official dataset and original results archive before running Notebook 05. For example, on DTU HPC:

```bash
git submodule update --init third_party/AnomalyDINO
export MVTEC_ROOT=/work3/s183356/datasets/mvtec_official
export VAD_RESULTS_ROOT="$HOME/msc-visual-anomaly-detection/results"
jupyter notebook notebooks/05_final_results.ipynb
```

The archive contains EXP-003 (or baseline_reproduction) and lighting_blur/blur_150. The panel generation verifies reference hashes, clean-run hashes, perturbed evaluation provenance, paired labels, archived scores, and the recomputed top-1% raw-map score. It uses the pinned upstream dists2map reconstruction (OpenCV linear interpolation and SciPy Gaussian sigma 4), preserves the paired color scale, and records the source-file hashes and mask statistics. The four measured cases and their provenance are in ../final_scientific_analysis/. Notebook 05 also plots all 83 Bottle score pairs from the full-precision export in ../lighting_blur/; no raw prediction archive is needed for that scatter plot. Without the dataset/archive environment variables, the notebook explicitly skips only the optional map-reconstruction cell. No new GPU inference is required.
