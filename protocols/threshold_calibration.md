# ADINO-CAL-P01 — independent normal-only threshold calibration
Exploratory additional analysis registered 26 November 2026 after completion of ranking-metric robustness analysis. It does not change the one-shot baseline, reference augmentation, original metrics or test images.
40 additional official train/good images per category, excluding all three fixed reference images. Freeze SHA-256 filename ordering before calibration, independently of test scores. Record file hashes; fail on overlap with reference hashes. Same set for all three reference choices. One-shot memory banks remain unchanged. This is one-shot reference detection with additional normal calibration data, not strictly one-shot in total data usage.
For each category/reference, compute 40 clean calibration scores using the original pinned AnomalyDINO pipeline and fixed settings. Threshold is 39th smallest score (ceil(41*0.95)); classify score > threshold as anomalous. Nominal 5% tail target, not guaranteed actual FPR, especially under distribution shift. No claim of formal conformal coverage; finite calibration sample, possible non-exchangeability and separately executed stochastic foreground masking limit inference. Do not tune thresholds against test labels, alter after seeing test results, or calibrate separately on perturbations. Freeze all 45 threshold records before reading archived test predictions. Evaluate original and four perturbations using same thresholds; report per-run FPR, FNR, TPR, counts, equal category and reference macro-averages and paired changes in percentage points. Shared test sets and references are not independent replicates. Baseline only; no claim about calibrated augmentation performance.
